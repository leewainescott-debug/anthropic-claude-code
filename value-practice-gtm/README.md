# The value practice, a go to market pack

This pack is the go to market offering and value solution for a value practice inside strategy at Slalom. It answers, in order, what value is, how to sell it, how to go to market with it, how to change the client conversation, how to open doors beyond the CTO, what clients will actually pay for, and how delivered value gets proven afterwards. Every claim carries evidence, every recommendation carries its reasoning and its consequence for what you do differently, and every structure has been tested for overlaps and gaps before it reached this page.

Read `01-the-answer.md` first; it holds the recommendation, the issue tree the questions imply, and the short form of every answer. The remaining files are the depth, built to be dipped into rather than read end to end.
